## `<arscene>`

Augmented reality on eskiu-packages/scene (`<arscene>`).

The pieces every AR app with a scene writes by hand, as ViroReact's AR scene navigator
does them: ArStage takes each frame of an eskiu-packages/ar session into the scene (the camera
picture behind it, the device as its camera, the real world's depth hiding what is behind
it); ArPlacer shows the surfaces found and puts content where the user taps
(ViroARPlaneSelector); ArMarkers keeps content on tracked images (ViroARImageMarker).

```eskiu
ArStage stage = ar_stage(&scene, cam)?;
ArPlacer placer = ar_placer(&scene, content)?;
use_ar_session(ArOptions{horizontal: true, depth: true}, void(*ArFrame frame) {
    stage.frame(&scene, frame, width, height)?;
    placer.frame(&scene, frame, width, height)?;
    if (tapped) placer.tap(&scene, frame, tap_x, tap_y, width, height);
    scene.render(view, width, height, format)?;
});
```

### ar_to_mat4

```eskiu
Mat4 ar_to_mat4(ArMat4 m)
```

ArMat4 and Mat4 share a layout (column major, 16 floats).

### ArStage

```eskiu
struct ArStage {
    int camera;
    float near;
    float far;
    bool occlusion;
    ArLight light;
}
```

What ArStage_frame does with each frame: the camera picture as the background, the
device's pose and projection for the scene's camera (near and far in meters), the real
world's depth for occlusion (when the session gives depth), the scene semantics for
semantic masks (when the session gives them), and the light estimate.

### ar_stage

```eskiu
Result<ArStage, string> ar_stage(*Scene scene, int camera)
```

A stage for scene's camera node `camera` (made with Scene_add_camera), with near 0.02 m,
far 100 m and occlusion on. The scene's background turns transparent: the picture shows
through it.

### ArStage_frame

```eskiu
Result<int, string> ArStage_frame(*ArStage self, *Scene scene, *ArFrame frame, uint32 width, uint32 height)
```

Takes frame into scene for a view of width x height pixels: draws the camera picture,
fitted to the view as the projection assumes, into the scene's camera_background; puts the
camera node at the device's pose with the session's projection; uploads the depth image as
the scene's occlusion depth; uploads the scene semantics as the scene's semantic textures.

### ArStage_release

```eskiu
void ArStage_release(*ArStage self)
```

Releases what the stage made (the scene keeps its borrowed ids, now pointing at nothing:
release the stage after the scene, or set camera_background and occlusion_depth to 0).


## `<arscene/anchors>`

Content kept where it was put in the real world (`<arscene/anchors>`). The
session refines its map as it learns the room, and a node at a fixed position in the
world's coordinates then shifts against the room; an anchored node does not. Each node gets
an anchor of the session at its place once tracking is normal, and from then on the
anchor's movement since then is the node's base (SceneNode.base): the node's own position,
its animations, drags and physics stay in its parent's coordinates, and only the session's
corrections move it.

```eskiu
ArAnchors anchors = ar_anchors();
anchors.add(&scene, content);
use_ar_session(ArOptions{}, void(*ArFrame frame) {
    anchors.frame(&scene, frame, time);
});
```

### ArAnchors

```eskiu
struct ArAnchors {
    List<_ArAnchored> list;
    int max_tries;
    double retry_seconds;
    float reanchor_distance;
}
```

Nodes anchored to the real world. A failed try (the session could not make an anchor) is
tried again retry_seconds later, up to max_tries (0: until it works); then the node is left
unanchored. Waiting
for tracking to be normal spends no try. A node moved more than reanchor_distance meters
away from its anchor gets a new anchor where it is (0: it keeps the first one).

### ar_anchors

```eskiu
ArAnchors ar_anchors()
```

An empty set: three tries a second apart, no re-anchoring.

### ArAnchors_add

```eskiu
void ArAnchors_add(*ArAnchors self, *Scene scene, int node)
```

Anchors node where it is once tracking is normal (ArAnchors_frame makes the anchor).

### ArAnchors_remove

```eskiu
void ArAnchors_remove(*ArAnchors self, *Scene scene, int node)
```

Stops anchoring node and removes its anchor from the session. The node keeps the base it
has (it does not jump); Scene_clear_base removes that.

### ArAnchors_anchored

```eskiu
bool ArAnchors_anchored(*ArAnchors self, int node)
```

True when node has an anchor in the session.

### ArAnchors_frame

```eskiu
void ArAnchors_frame(*ArAnchors self, *Scene scene, *ArFrame f, double time)
```

Each frame: makes the anchors not made yet (tracking normal), moves each anchored node by
its anchor's movement since it was made, and re-anchors a node that moved far from its
anchor. A node removed from the scene loses its anchor. time is seconds on any clock that
only goes forward.

### ArAnchors_free

```eskiu
void ArAnchors_free(*ArAnchors self)
```

Removes every anchor from the session and forgets the nodes.


## `<arscene/collide>`

The real world as something to collide with (`<arscene/collide>`), for devices
without LiDAR's world mesh: the depth image (LiDAR, ARCore's Depth API, or a depth model)
turned into a triangle mesh in the world and kept as a static body, rebuilt as the session
sees more (ViroReact's physics against the depth mesh). With LiDAR, ArWorldMesh.physics does
the same from the reconstruction.

### ar_depth_triangles

```eskiu
int ar_depth_triangles(*ArFrame frame, int step, float max_jump, *List<Vec3> out)
```

The depth image as world triangles into out (three corners each): a grid every `step`
depth pixels, two triangles a cell, a cell left out where the depth is unknown or jumps
by more than max_jump of itself (an object's edge, not a surface). The count of corners.

### ArDepthCollider

```eskiu
struct ArDepthCollider {
    int step = 4;
    float max_jump = 0.1;
    int every = 15;
    string tag;
}
```

The depth image as a static body of a physics world, under a node of its own at the
scene's root: rebuilt each `every` frames from the latest depth (a grid every `step`
pixels). tag names it for collision handlers.

### ar_depth_collider

```eskiu
ArDepthCollider ar_depth_collider(*Scene scene)
```

A collider for scene's world.

### ArDepthCollider_frame

```eskiu
int ArDepthCollider_frame(*ArDepthCollider self, *Scene scene, *ScenePhysicsWorld world, *ArFrame frame)
```

Takes a frame: every `every` frames with depth, the body becomes the depth's mesh (none
when the frame has too little depth). The body's id while there is one.

### ArDepthCollider_free

```eskiu
void ArDepthCollider_free(*ArDepthCollider self)
```

Frees the collider's corners (the node and body stay with the scene and the world).


## `<arscene/markers>`

Content on tracked images and objects (`<arscene/markers>`),
ViroARImageMarker and ViroARObjectMarker: a node per target follows its pose while it is
tracked, hidden while it is not, with a handler told when each is found and lost.

### ArMarkers

```eskiu
struct ArMarkers {
    List<_ArMarker> list;
    bool keep_last_known;
    fn(int, bool)->void _handler;
}
```

Nodes on image targets. keep_last_known keeps a node where its image was last seen when
the platform only knows it from before (ArImageLastKnown) instead of hiding it.

### ar_markers

```eskiu
ArMarkers ar_markers()
```

An empty set of markers, keeping last known poses.

### ArMarkers_add

```eskiu
void ArMarkers_add(*ArMarkers self, *Scene scene, int image, int node)
```

Puts node on the image target at `image` (its index in ArOptions.images), hidden until it
is found. The node's own transform is replaced by the image's pose (x to the picture's
right, z toward its bottom, y out of its face): put the content under it.

### ArMarkers_add_object

```eskiu
void ArMarkers_add_object(*ArMarkers self, *Scene scene, int object, int node)
```

Puts node on the object target at `object` (its index in ArOptions.objects, ARKit), hidden
until it is found; the node takes the reference object's pose (ViroARObjectMarker). The
handler hears of it with the object's index.

### ArMarkers_on_change

```eskiu
void ArMarkers_on_change(*ArMarkers self, escaping fn(int, bool)->void handler)
```

Calls handler(image, found) when an image is found (true) or lost (false), as
ViroARImageMarker's onAnchorFound and onAnchorRemoved.

### ArMarkers_frame

```eskiu
void ArMarkers_frame(*ArMarkers self, *Scene scene, *ArFrame frame)
```

Moves each marker's node to its image in frame.

### ArMarkers_free

```eskiu
void ArMarkers_free(*ArMarkers self)
```

Frees the markers and their handler.


## `<arscene/placer>`

Tap to place (`<arscene/placer>`), ViroARPlaneSelector's flow: the surfaces the
session finds drawn as translucent shapes, a ring where the middle of the view meets one,
and the content (a node, hidden until then) put on the surface the user taps, turned to
face them, with a floor under it that shows its shadows on the real one.

### ArPlacer

```eskiu
struct ArPlacer {
    int content;
    float scale;
    bool show_planes;
    bool show_reticle;
    bool shadows;
    bool hide_planes_when_placed;
    int kinds;
    bool use_depth;
    bool placed;
    bool center_hit;
    int center_kind;
    int64 plane;
    Vec4 plane_color;
}
```

A placer for node `content`. scale is the content's size once placed; show_planes,
show_reticle and shadows (the shadow-catching floor under the content, which needs a light
that casts shadows) are on by default; hide_planes_when_placed hides the surfaces after a
placement. kinds limits placement to planes of those ArPlaneClass values (a bit per class,
0 for any); use_depth also places on real surfaces the depth image sees where no plane was
found (ArOptions.depth). After each frame, placed says whether the content is down, center_hit whether
the middle of the view meets a surface and center_kind its class; plane is the id of the
plane the content stands on.

### ar_placer

```eskiu
Result<ArPlacer, string> ar_placer(*Scene scene, int content)
```

A placer for content (hidden until placed), with a translucent violet for the surfaces.

### ArPlacer_frame

```eskiu
Result<int, string> ArPlacer_frame(*ArPlacer self, *Scene scene, *ArFrame frame, float width, float height)
```

Draws the surfaces of frame and the ring at the middle of the view (width x height).

### ArPlacer_place

```eskiu
void ArPlacer_place(*ArPlacer self, *Scene scene, ArMat4 pose, int64 plane)
```

Puts the content at pose (y along the surface's normal), turned about it to face the
viewer, at its scale, and shows it.

### ArPlacer_tap

```eskiu
bool ArPlacer_tap(*ArPlacer self, *Scene scene, *ArFrame frame, float x, float y, float width, float height)
```

Places the content where a tap at (x, y) of the view (width x height) meets a surface;
false when it meets none (of the allowed kinds).

### ArPlacer_reset

```eskiu
void ArPlacer_reset(*ArPlacer self, *Scene scene)
```

Hides the content again, for a new placement.

### ArPlacer_free

```eskiu
void ArPlacer_free(*ArPlacer self)
```

Frees the placer's lists (its nodes stay in the scene).


## `<arscene/world>`

The real world's mesh in the scene (`<arscene/world>`), ViroReact's world mesh:
each piece eskiu-packages/ar reconstructs (LiDAR, ArOptions.mesh) as a node of the scene, an
invisible occluder by default (virtual content goes behind real walls and furniture) or a
translucent surface to see what the device has mapped. A piece is rebuilt only when the
session updates it.

### ArWorldMesh

```eskiu
struct ArWorldMesh {
    int root;
    *ScenePhysicsWorld physics;
    string tag;
    bool occlude;
    bool show;
    Vec4 color;
}
```

The world's mesh in a scene. show draws it in color (to see what was mapped) instead of
as an occluder; occlude (on) hides virtual content behind it. The pieces are children of
root (the scene's root unless set before the first frame), so a scene whose space is not
the session's puts the session's space in root's transform. With `physics` set, each piece
is also a body of that world (kinematic, following the piece, tagged `tag` or "world"), so
virtual objects land on and bump into the room (ViroReact's physics against the world mesh).

### ar_world_mesh

```eskiu
ArWorldMesh ar_world_mesh(*Scene scene)
```

The world's mesh for scene: occluding, not shown.

### ArWorldMesh_frame

```eskiu
Result<int, string> ArWorldMesh_frame(*ArWorldMesh self, *Scene scene, *ArFrame frame)
```

Brings the scene's pieces up to frame's meshes: new pieces added, updated ones rebuilt,
gone ones hidden.

### ArWorldMesh_count

```eskiu
int ArWorldMesh_count(*ArWorldMesh self)
```

The number of pieces in the scene.

### ArWorldMesh_free

```eskiu
void ArWorldMesh_free(*ArWorldMesh self)
```

Frees the list (the nodes stay in the scene).
